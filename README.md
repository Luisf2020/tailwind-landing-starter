Landing base con Tailwind CSS 3: tema propio, componentes con @apply y utilidades responsive.

> **Transparencia sobre IA:** este proyecto se desarrollo con asistencia de inteligencia artificial (generacion de codigo, revision y documentacion). El codigo fue leido, ejecutado y probado manualmente antes de publicarse. No declara clientes, metricas ni resultados que no puedan verificarse.

## Problema que resuelve

Disenar una landing sin escribir CSS repetitivo ni inventar un sistema de colores desde cero.

## Solucion implementada

Configuracion de Tailwind con tokens propios, componentes de proyecto con @apply y utilidades responsive en el marcado.

### Funcionalidades principales

- Tokens de color personalizados
- Componente .btn con @apply
- Diseno responsive con utilidades
- Build minificado a dist/

## Stack

- Tailwind CSS 3
- HTML

## Estructura

```
tailwind.config.js  # tema y content
src/input.css       # directivas y componentes
index.html          # marcado
```

## Puesta en marcha

```bash
npm install
npm run build
# abrir index.html
```
