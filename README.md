# tailwind-landing-starter

Landing base con Tailwind CSS 3: tema propio, componentes con @apply y utilidades responsive.

> Proyecto de portafolio de Luis Felipe Zuniga Leon. Desarrollado con asistencia de IA
> (generacion de codigo, revision y documentacion); el codigo fue revisado y probado manualmente.
> No declara clientes, metricas ni resultados no verificables.

## Stack

- Tailwind CSS 3
- HTML

## Como ejecutar

```bash
npm install
npm run build
# abrir index.html
```

## Estructura

```
tailwind.config.js  # tema y content
src/input.css       # directivas y componentes
index.html          # marcado
```
